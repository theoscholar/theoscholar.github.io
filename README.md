# Jeremiah — Study Notes

A static site of verse-by-verse Bible study notes on the book of Jeremiah, ready for GitHub Pages.
Open `index.html` for the landing page. All pages are self-contained HTML with no external dependencies.

## Publishing to GitHub Pages

From inside your local clone of the repo, copy every file from this folder in, then:

    git add .
    git commit -m "Add Jeremiah study notes site"
    git push

On GitHub: Settings -> Pages -> Build and deployment -> Source: Deploy from a branch,
select your default branch and the / (root) folder, then Save.
The site appears at https://<your-username>.github.io/<repo-name>/ within a minute or two.
